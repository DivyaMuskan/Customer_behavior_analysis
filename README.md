🚀 Project Workflow / Steps
1. Data Loading

Imported dataset using pandas.read_csv()

Checked dimensions, data types, and basic summary statistics

Verified data import quality and structure

2. Exploratory Data Analysis (EDA)

Identified missing values, outliers, and data distributions

Univariate, bivariate, and multivariate analysis

Created visualizations (histograms, bar charts, boxplots, correlation matrices)

Understood patterns, trends, and relationships in the data

3. Data Cleaning

Handled missing values (imputation/removal)

Treated outliers using IQR or domain-based rules

Converted data types and encoded categorical values

Standardized column names for clarity

Removed duplicates and invalid entries

4. Power BI Dashboard Development

Imported cleaned dataset into Power BI

Created measures, DAX calculations, and filters

Designed interactive visualizations such as:

KPI cards

Bar & Line charts

Slicers

Drill-down views

Built a clean, minimal, recruiter-friendly dashboard

5. Report & Presentation (Gamma)
